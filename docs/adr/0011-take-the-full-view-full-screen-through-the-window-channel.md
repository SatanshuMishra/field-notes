# Take the full view full screen through the window channel

Status: accepted

The full view's full-screen button makes the real window full screen through the app's own window channel, with a setFullScreen method answered natively, and the window reports its real full-screen state as part of the window state the channel already sends when it opens and on every change. On macOS the window moves into its own full-screen space. On Windows the app saves the window's placement and style, removes the frame and covers the monitor the window is on, then restores both exactly, because a maximised window keeps its caption and taskbar and is not full screen; the caption buttons and the top resize band hide meanwhile. The full view follows the reported state rather than a flag of its own, so a change made with the system's own controls also changes its layout and what Esc does, and it returns the window to windowed on leaving only when it made the window full screen, so a window the person made full screen another way stays as it was. A third-party window package was not taken, since the window channel already carries the app's other window calls and its state reports. Android gets no full-screen button.
