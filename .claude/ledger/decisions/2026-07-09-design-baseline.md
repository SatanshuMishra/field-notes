## Context
The user supplied a Claude Design prototype ("Field Notes") as the canonical visual design, imported via the DesignSync MCP.

## Decision
The "Field Notes" prototype is the design baseline the app is built against. Fonts: Newsreader (serif), Instrument Sans (UI), Caveat (handwritten). Warm paper palette (page #d9cbb2, panel #efe2ce, coral #c76a54 primary, sage #7d8450, ink #4a3b2e). "Sticker cutout" cel-shaded treatment: 1.5px ink outline + hard non-blurred offset shadow, dashed dividers, cross-hatch photo textures, hand-drawn SVG flowers, paper grain, playful motion. The Settings page defines the reusable field-style catalog for all controls.
